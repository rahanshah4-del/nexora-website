# Docs Studio screenshots

Playwright captures of `/tools/invoice-generator/` for reviewing UI changes
without running the app. Regenerated by hand; not used by the build.

## part0-preview-layout/

`before/` is the Step 2 build (c23a0f4), `after/` is the fixed layout. Files are
`{width}-{theme}-{n}-{view}.png`:

- `1-top`: the tool scrolled into view.
- `2-scrolled` (1024 px and wider): scrolled 1200 px into the editor. In
  `before/` the preview has scrolled away and the right half is empty.
- `2-preview-tab` (768 and 390 px): the mobile Preview tab, clipped to the tool
  area plus the start of the footer.

Root causes fixed:

1. `body { overflow-x: hidden; overflow-y: auto }` from the site CSS made
   `<body>` a scroll container that never scrolls, so the sticky toolbar and
   preview never stuck (empty right column while editing).
2. `.ds-studio` had `min-height: 900px`, leaving a blank band below short
   content (mobile preview, receipts).
3. The preview column had a fixed viewport height instead of a max height, so
   short papers sat in a tall grey box.
4. The scaled paper stayed in normal flow; it is now absolutely positioned
   inside a wrapper sized to the measured height × scale (ScaledPaper.jsx),
   so a transform can never leave unscaled empty space.
